☁️ Google Drive 同步設定說明

CardFlow 是 100% 用戶端本地執行的應用程式。為了直接連結您的個人 Google Drive 進行私密備份，只需在 Google Cloud 免費建立一個 OAuth 用戶端 ID：

  1. 前往 Google Cloud Console：登入並進入 API 與憑證頁面。
  2. 啟用 Google Drive API：在「已啟用的 API 和服務」搜尋並啟用 Google Drive API。
  3. 建立 OAuth 用戶端 ID：點選「建立憑證」➔ 選擇「OAuth 用戶端 ID」➔ 應用程式類型選「網頁應用程式 (Web application)」。
  4. 設定授權來源：在「已授權的 JavaScript 來源」填入目前 CardFlow 的網址（例如：http://localhost:8000 或您的自訂網址）。
  5. 貼上 Client ID：將產生的 xxxxx.apps.googleusercontent.com 複製並貼回上方輸入框，點擊「儲存」即可完成！
🔒 隱私承諾：CardFlow 僅請求 drive.file 最小授權，只能存取 CardFlow 建立的 cardflow_backup.json 檔案，絕對無法檢視您雲端硬碟中的任何其他檔案。
